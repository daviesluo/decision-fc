# Decision FC: how the game works

This branch serves **https://daviesluo.github.io/decision-fc/**, my write-up of how Decision FC is designed and tested. The game's source is on the [`main` branch](https://github.com/daviesluo/decision-fc), and the game is at [decisionfc.com](https://decisionfc.com).

- `index.html` and `style.css`: the page. No build step, no scripts.
- `assets/img`: screenshots from the game.
- `assets/fonts`: Barlow and Barlow Condensed, under the SIL Open Font License (`OFL-*.txt`).
