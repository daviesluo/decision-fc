# This has to exist as a real file. The worker serves index.html for any path it
# does not recognise (`not_found_handling: single-page-application`), so before
# this existed /robots.txt answered 200 with the app's HTML — which is not a
# robots file, and is the kind of thing that makes a crawler treat a new domain
# as broken rather than as permissive.
